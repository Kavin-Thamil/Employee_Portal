# Employee Portal on AWS

A cloud-based Employee Portal deployed on AWS using Flask and multiple AWS services.

## Features
- Employee login system
- Document upload functionality
- AWS S3 cloud storage integration
- EC2 deployment using Linux server
- Application Load Balancer integration
- CloudWatch monitoring and SNS alerts
- IAM role-based AWS access
- SQLAlchemy database integration

## AWS Services Used
- EC2
- S3
- IAM
- CloudWatch
- SNS
- Application Load Balancer
- Security Groups

## Tech Stack
- Python
- Flask
- SQLAlchemy
- HTML
- Bootstrap
- AWS

## Architecture
User → Load Balancer → EC2 Flask App → S3 Storage

- AWS cloud deployment
- Linux server management
- Cloud storage integration
- Infrastructure monitoring
